# Online Exam Portal — Software Engineering Mini-Project (Part-1)

A web-based portal for creating, conducting and automatically evaluating online exams.
Roles: **Student**, **Teacher/Examiner**, **Administrator**.

## Deliverables (Part-1)
| Document | File | Standard |
|---|---|---|
| Software Requirements Specification | [docs/SRS.pdf](docs/SRS.pdf) | IEEE 830 / 29148 |
| Test Plan (with 23 test cases and traceability) | [docs/Test_Plan.pdf](docs/Test_Plan.pdf) | IEEE 829 |
| Software Architecture & Design Specification | [docs/Architecture_Design.pdf](docs/Architecture_Design.pdf) | IEEE 1016 |

Editable Word versions are in `docs/`; UML diagrams are in `diagrams/`.

## Highlights
- 21 functional, 10 non-functional and 10 security requirements (unique IDs, measurable)
- UML use case, component and two sequence diagrams
- Layered client–server architecture with a modular REST service design
- Full requirement → test case traceability matrix
